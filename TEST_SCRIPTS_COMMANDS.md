
## How to Use These Scripts

### Windows Users:
1. **Setup**: `.\setup-tests.ps1`
2. **Run all tests**: `.\run-tests.ps1`
3. **Run specific components**: 
   - `.\run-tests.ps1 -Frontend`
   - `.\run-tests.ps1 -Backend` 
   - `.\run-tests.ps1 -Api`
4. **Verbose output**: `.\run-tests.ps1 -Api -Verbose`

### Linux/Mac Users:
1. **Setup**: `./setup-tests.sh`
2. **Run all tests**: `./run-tests.sh`
